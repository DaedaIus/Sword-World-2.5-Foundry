# Sword World 2.5 for Foundry VTT

An unofficial English-language Sword World 2.5 game system, poorly made for Foundry VTT 14.

## Features
- Character sheets based on English Language sheets made by Mugen
- Automatic Hit, power table, rest, and damage calculation
- Import ability from https://sw25.wikidot.com/ for classes, items, races, spells and feats
- Optimism that exceeds ability in coding!
- Abstract Battlemaps preloaded in
